My work

Battleship

This is a web application that provides an interface for users to play games of Battleship, with support for either one player games against a bot, or two player games where the device is passed between players. It features extensive drag and drop functionality, and an advanced bot player algorithm that uses probability to attack positions that are statistically the most likely to have a ship.

Weather App

This is a web application that utilizes a combination of requests from various APIs to serve formatted weather information to the user, for either their current location or a location of their choice. It utilizes the Visual Crossing Weather API for obtaining weather information, the Geolocation Web API for obtaining user coordinates, and the TomTom Maps API for parsing coordinates into a city and state.

Todo List

This is a todo list web application that provides an interface similar in structure to a file explorer, where users have the ability to create and save an organized system of projects containing checklists of tasks sorted by date. It utilizes advanced DOM manipulation techniques to enhance user experience by ensuring that this interface is simple to navigate and understand.

Restaurant Page

This is a mock restaurant website that was created primarily using JavaScript to dynamically generate its content through the DOM. It contains several pages, all of which are loaded through functions provided by ES6 modules, and bundled together with an HTML template and CSS stylesheets through the use of Webpack.

Tic Tac Toe

This is an interactive webpage that was created using HTML, CSS and JavaScript, utilizing advanced OOP techniques. It allows two players to set their names, and play endless rounds of tic-tac-toe with each other.

Library

This is an interactive webpage that was created using HTML, CSS, and JavaScript. It provides a responsive interface created via CSS Grid and DOM manipulation to display, create, remove, and modify the read status of books.
